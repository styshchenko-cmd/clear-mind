# clear-mind

ClearMind is a browser extension that gives you back your attention. You put the
rules on yourself: block a site, give it a daily time limit, or hide the parts of
it that keep you scrolling. Unlocking takes your password **and** a cooldown
(30 s by default), which is just enough friction to ask "do I actually need this?".

Everything runs inside the extension. It makes no network requests, has no
servers and no analytics, and stores all data in the browser.

## Features

- **Per-site rules**: *block* (always shows the block page), *time limit*
  (N minutes per day, resets at 00:00 local) or *watch* (track time only).
- **Block page** with your own message, or a redirect to a URL you choose.
- **Unlock** = password + per-site cooldown. An unlock is bound to the tab and
  lasts until you close the tab or until midnight, whichever comes first.
- **Auto mode**: block whole categories (adult, social feeds, news, video &
  streaming, shopping, gambling) with bundled domain lists, either for a
  focus window (25 min, 2 h, until 18:00, rest of today) or always.
  Adult and gambling are always blocked completely while switched on.
- **Modify view** for reddit, YouTube, X, Instagram, Facebook and LinkedIn: hide
  feeds, Shorts/Reels, recommendations, trends, notification badges, comments; and
  optionally show the page in grayscale.
- **Stats**: time on listed sites, blocks shown, unlocks, under-limit streak,
  per-site and per-category usage, and a 7- or 30-day chart.
- **Password-guarded loosening**: removing a site, weakening a rule, switching off
  a running category or "block completely", and resetting stats all ask for the password.

## Install (development)

**Brave / Chrome / Chromium / Edge**

1. Open `brave://extensions` (or `chrome://extensions`).
2. Turn on *Developer mode*.
3. Click *Load unpacked* and pick the `src/` folder (or `dist/chrome/` after a build).

On first install the settings page opens: set a password there first.

**Firefox / Zen** (build is produced, not yet tested by hand)

```sh
npm run build
```

Then open `about:debugging#/runtime/this-firefox` → *Load Temporary Add-on…* →
`dist/firefox/manifest.json`. Firefox 121 or newer is required.

**Safari**: planned. Convert `dist/chrome/` with `xcrun safari-web-extension-converter`.

## Development

There is no bundler and there are no runtime dependencies: plain ES modules, loaded
as-is.

```sh
npm test        # unit tests (node:test) for rules, stats, time, passwords, data files
npm run e2e     # builds, then drives headless Brave over CDP; screenshots in dist/e2e/
npm run build   # dist/chrome/, dist/firefox/ and zip archives
npm run lists   # re-download the adult and gambling lists (the only networked script)
```

`npm run e2e` launches Brave (override with `BROWSER=chromium`). Every hostname
resolves to a local test server, so the test never touches the real sites. Branded
Google Chrome 137+ ignores `--load-extension`, so use Brave or Chromium.

### Layout

```
src/
  manifest.json              Chromium manifest (Firefox variant generated by the build)
  background/service-worker.js  blocking, time tracking, unlocks, password-guarded changes
  lib/                       pure logic shared by the pages and the worker
    rules.js                 the block/allow decision
    model.js                 data model, categories, defaults, "does this loosen?" checks
    stats.js                 recording and summarising usage
    domain.js time.js password.js lists.js ui.js api.js
  pages/                     popup, block page, unlock cooldown, options (hash-routed)
  content/modify.js          injects modify-view CSS on supported sites
  shared/adapters.js         per-site selectors for modify view
  lists/                     category domain lists (see lists/SOURCES.md)
  styles/                    clearmind.css (design tokens) and bundled IBM Plex Mono
test/                        unit tests
scripts/                     build, e2e, list refresh
```

### How blocking works

The worker listens to `webNavigation.onBeforeNavigate` and `onCommitted` for top-level
frames and sends the tab to `pages/blocked.html` (or the user's redirect) when the
rule says so. A 30-second alarm, plus tab, window and idle events, credit time to the
site in the foreground. That same check catches a time limit that runs out mid-visit.
Time counts only while the browser window has focus and you're not idle (unless the
tab is playing audio).

Permissions: `storage`, `tabs`, `webNavigation`, `alarms`, `idle`, plus content
script access to the six modify-view sites only. There is no `<all_urls>` host
access. The extension pages' CSP sets `connect-src 'self'`.

## Data and privacy

All state lives in `chrome.storage.local` (rules, stats, password hash) and
`chrome.storage.session` (active unlocks). The password is stored as a salted
PBKDF2-SHA256 hash and cannot be recovered. Stats are kept for 400 days.
